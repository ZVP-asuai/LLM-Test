# ADR-0001: Структура репозитория лаборатории

- Статус: принято
- Дата: 2026-11-24

## Контекст
Нужен долговременный журнал для нескольких GPU, моделей и inference-движков. Результаты должны быть воспроизводимы, сравнимы и наглядно представлены в браузере.

## Решение
- JSON — канонический формат benchmark-записи.
- Markdown — методика, журнал и технические решения.
- YAML — инвентаризация оборудования.
- HTML/CSS/vanilla JS — статическая панель без внешних CDN.
- Git commit history — история изменений и аудит.
- GitHub Pages — публикация каталога docs/.

## Последствия
Данные машинно-анализируемы, отчёты не зависят от сторонних библиотек, новые GPU и модели добавляются без перестройки. Dashboard JSON и HTML-отчёт обновляются при фиксации каждого нового результата.
