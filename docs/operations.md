# Операционные ограничения CT128 GPU LAB

Разрешённая зона — только CT128. Команды для контейнера запускаются владельцем с Proxmox HOST через pct exec 128 -- ...; не просить вручную входить в контейнер.

Примеры команд с HOST:

    pct exec 128 -- nvidia-smi
    pct exec 128 -- bash -lc 'ps aux'

CT130 и CT132 — production: не подключаться, не изменять, не останавливать, не обновлять и не перезапускать. Не использовать pct exec 130/132.

Не подключаться к Proxmox HOST удалённо. Не менять конфигурацию хоста, PCIe, IOMMU, драйверы, hookscript, системные библиотеки и настройки контейнеров без отдельного согласования.

Inventory содержит последнюю предоставленную владельцем конфигурацию; перед любыми изменениями её необходимо повторно проверить с HOST. Наличие GPU в планах не означает, что она уже проброшена в CT128.

Порядок изменения: сохранить исходное состояние → сформулировать гипотезу → изменить один фактор → измерить → проверить качество/стабильность → сохранить откат.

В Git не хранить секреты, токены, ключи, персональные данные, полные дампы окружения и веса моделей. Логи проверять перед публикацией.
