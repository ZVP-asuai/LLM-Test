# CEB — подготовка владельцем до начала теста
Ревизия delivery-2026-11-25-r3. Сохранены 50 заданий и их веса. Публичный офлайн-пакет содержит учебные PDF, изображения, корпуса, CSV/HTML/SQL, инструмент, манифест и схемы. **Не содержит внешние оригиналы, лицензированные нормы или SDK**.
1. Скачайте ZIP сами, до запуска модели. Если чат не открывает ZIP, распакуйте и передайте нужные файлы. Не давайте агенту права читать результаты и генератор входов.
2. Положите оригиналы с точными именами из delivery-contract.json в sources. Скачивайте разрешённым способом. Для NVE41289.09 нужен исходный PDF и только страница 116 на вход модели; размер оригинала и 403 больше не должны мешать решению. Не публикуйте лицензированные материалы.
3. Установите PyMuPDF в отдельной среде владельца; выполните:
```
python ceb-prepare.py --pack CEB-offline-inputs.zip --sources sources --output prepared-preview
```
Опция --fetch пробует указанные источники только на этапе подготовки. Просмотрите preflight.json, выбранные страницы и редакции; заполните source-approval-template.json проверенными SHA-256 и reviewed:true. Проверьте инструменты в реальной среде, заполните runtime-template.json только фактическими результатами. Повторите в новом каталоге с --approved approvals.json --runtime runtime.json --strict. Код 2 означает неполную готовность Standard. Для квалификации нужны также все 6 дополнительных.
4. Оркестратор передаёт только tasks/<id>.json, перечисленные входы, output-contracts.json и для CAD11 собственный STEP CAD10; отдельный контекст. Таймер после доставки. Запрет сети во всех задачах кроме №48. Чат использует START.txt и вложения; он не является независимым измеряемым прогоном.
5. Контекст: реальные входные токены с учётом chat template/system, резерв и отсутствие truncation. Файловый поиск не равен нативному окну. Требуется адаптер конкретного движка. SDK EPLAN 2025 и нормы — локальные оригиналы владельца. Оценщик отдельно проверяет факт исполнения и инженерную правильность. Скрипт preflight проверяет файлы и наличие заявленных владельцем подтверждений, но не доказывает достоверность runtime-проб.
