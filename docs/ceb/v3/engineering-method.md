# CEB 3.0 — инженерный комплекс

Единый каталог — engineering.json. Нумерация 1–100, один балл за задание (предложенная шкала, до квалификации). GPT-6.2 с максимальным доступным рассуждением — базовая модель. Модель не является эталоном. Эталон и критерии утверждаются независимой проверкой до зачёта. Пакет пилотный: полная независимая проверка ответов и повторяемый запуск на двух средах ещё не выполнены.

## Запуск
1. Получить один ZIP, сверить SHA-256, открыть engineering.json. Данные в пакете; для PDF приложены изображения страниц. Не требуется установка ПО.
2. Выполнить все задания в чистой рабочей папке. Разрешён стандартный Python, локальные файлы и визуальное чтение. Никаких действий на реальном хосте.
3. Заполнить engineering-report.json и приложить выходные файлы. Один объект на каждый из 100 ID. Хеш относится к полученному архиву. Сохранять проверяемые расчёты, не внутренний поток рассуждения.
4. Проверяющий сравнивает ответы, выполняет код, открывает артефакты и сверяет критерии. Принять оценки только с закрытым независимым ключом. Статус выполнения не равен баллу. Неподтверждённые проверки отдельно от фактических.

## Поля отчёта
answer — конечный ответ (объект, массив, число или текст).
calculation_steps — массив объектов {description, inputs, formula_or_method, substitution, result, unit}; для программ указывать наблюдаемую логику, а не выдуманный расчёт.
sources — массив {file, locator, fact}; для встроенных данных file="engineering.json", locator="номер задачи / фрагмент".
assumptions — массив строк.
checks — массив {name, expected, observed, status, evidence}; status: pass/fail/not_run. Реальная проверка должна иметь наблюдаемый результат; для not_run — null.
artifacts — массив относительных путей.
issue — null при completed, иначе {category, code, description, attempts}; category: model_error, environment, missing_input, ambiguous_task, timeout, not_run, unknown. Это предварительная классификация модели; проверяющий может изменить её.
wall_seconds — измеренное время или null.
timing.source — external, chat_observed или none. Неизмеренные значения null. 
## Оценка
Каждое задание: 1, 0.75, 0.5, 0.25, 0; заранее фиксировать доли критериев и допуски. Критические ошибки выделять отдельно. Не исключать неудобные задания задним числом. Блокер обязательной среды делает полный рейтинг неквалифицированным, но не запрещает диагностический анализ. До независимого ключа сайт показывает статусы, а не вычисляет качество по самоотчёту. Опубликованные оценки имеющихся протоколов относятся к их собственному набору входов, не переносятся на этот каталог.
