ОТДЕЛЬНО О ВРЕМЕНИ: start→init измеряет доставку вместе с подготовкой до init; setup_seconds измеряет init, verification_seconds — финальную проверку до упаковки; total_seconds — фактическое время от start (либо init) до последней финальной проверки с паузами, без последней сериализации. Ожидаемый отказ (отрицательный тест) со статусом pass означает совпадение ожидаемого и наблюдаемого отказа. Для ожидаемого отсутствия значения observed={"found":false,"value":null}, а не выдуманное значение. Не добавляй необязательные непроведённые тесты в список обязательных проверок.
