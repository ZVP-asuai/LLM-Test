Формат резервного JSON (если оригинальный шаблон недоступен):
{"format":"ceb-engineering-report-1","dataset_id":"ceb-100-portable-20261125-r2","run_id":"уникальный ID","model":{"name":"модель","reasoning_effort":null,"platform":null},"input_sha256":null,"timing":{"source":"none","delivery_seconds":null,"setup_seconds":null,"solve_seconds":null,"verification_seconds":null,"total_seconds":null},"tasks":[...],"delivery_attempts":[...]}
Каждая запись tasks: {"number":1,"id":"engineering","status":"completed","answer":{},"calculation_steps":[{"description":"...","inputs":{},"formula_or_method":"...","substitution":"...","result":null,"unit":"..."}],"sources":[{"file":"engineering.json или встроенный текст","locator":"№ задания / фрагмент","fact":"..."}],"assumptions":[],"checks":[{"name":"...","expected":null,"observed":null,"status":"not_run","evidence":null}],"artifacts":[],"wall_seconds":null,"issue":null}. При partial/failed/blocked/timeout/not_run issue={category,code,description,attempts}. category: model_error, environment, missing_input, ambiguous_task, timeout, not_run, unknown. Неизмеренные значения null. delivery_attempts — журнал попыток доставки, а не оценка задачи.

Для нового протокола timing.source допустим none, external, chat_observed, agent_monotonic. Добавь execution:{protocol:"ceb-execution-1",started_at,updated_at,timing_scope,clock_events:[{number,start_utc,end_utc,wall_seconds,source}],counts,attempted_tasks,measured_tasks,task_time_coverage,next_task,complete_submission,artifact_manifest:[{path,bytes,sha256}]}. Неизвестные поля null, не выдумывать. timing.solve_seconds — сумма только измеренных задач; не приписывать её всему тесту. В delivery_attempts фиксируй channel, action, status, error, bytes, sha256, elapsed_seconds. Если внешний наблюдатель измерил весь сеанс, укажи отдельно и источник. Общий статус выводится из 100 задач, не задаётся произвольно. При итоговой сдаче с отсутствующими задачами выводи диагностический отчёт, а не полный рейтинг.
