# CEB 3.1-portable — проект новой редакции (не активирован)

CEB 3.0 остаётся неизменным для начатых GPT/GLM прогонов, входной ZIP и SHA-256 не изменены. Цель 3.1: воспроизводимый инженерный тест без обязательных коммерческих SDK, сетевого доступа и закрытых документов. Переносить старые баллы на 3.1 нельзя.

Названия EPLAN допустимы только как отраслевой контекст, без требования запуска EPLAN. №83: заранее задать глубину всех элементов и считать обоснованный fit=false корректным ответом при несовместимых ограничениях. №100: потребовать тестируемое состояние автомата и воспроизводимые FAT-сценарии, отдельно ST; компиляция/runtime ПЛК — факультативная квалификация, не выдавать Python-симуляцию за IEC 61131-3.

## Условия выпуска
- Фиксированный полный ZIP, внутренняя опись, хеш и прямое вложение как равноправная доставка; все обязательные учебные материалы локальны.
- Проверить запуск на чистой среде без сети; подготовить открытые инструменты STEP/DXF/PDF/CSV/SQL/HTML; если инструмента нет, явно фиксировать блокер среды.
- Числовые поля, единицы, абсолютные/относительные допуски, допустимые альтернативы и веса задавать до запуска. Отдельный критерий качества доказательств; не наказывать отсутствие опционального инструмента как ошибку ответа.
- Независимо проверять реальные файлы и исполняемый код; для CAD использовать повторный импорт и геометрические проверки, не только скриншоты. Для логики использовать независимые тестовые векторы.
- Эталонные ответы и тесты приёмки хранить отдельно от пакета агента. Для релиза подготовить новые PDF/чертежи/JSONL, контракты, эталон и автоматические валидаторы; провести пробный full100 на двух различных средах. До этого 3.1 — проект, не действующий тест.
