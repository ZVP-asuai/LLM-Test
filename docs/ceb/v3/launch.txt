# CEB Engineering Benchmark 3.0-review — агент, 100 задач

Выполни задачи, а не обзор. Профиль full100 (50 прежних + 50 новых); по явному выбору владельца core50. Это новая версия, не смешивать с результатами 2.0.

ЭТАП A — ДОСТАВКА И ПОДГОТОВКА, максимум 1800 с отдельно от решения. Если владелец приложил CEB-3.0-inputs.zip, используй его. Иначе скачай именно ZIP (не весь репозиторий): https://zvp-asuai.github.io/LLM-Test/ceb/v3/CEB-3.0-inputs.zip ; резерв GitHub raw: https://raw.githubusercontent.com/ZVP-asuai/LLM-Test/ceb-inputs/CEB-3.0-inputs.zip . Ссылка на зеркало Google Drive публикуется на странице запуска после проверки зеркала. Сверь SHA-256 по https://zvp-asuai.github.io/LLM-Test/ceb/v3/sha256.txt и inventory.json. При неудаче одного канала попробуй другой или используй вложение. Не загружай результаты, эталоны, историю Git, валидаторы. Распакуй архив в отдельную рабочую папку. В корне manifest.json, extension-tasks.json, run-template.json, SETUP.md; прежние входы — legacy/, новые — extension/. Для старых задач используй legacy/catalog.json, legacy/delivery-contract.json, source-acquisition-lock.json. До старта разрешено получить указанные оригиналы по точным адресам и сверить хеши/редакции; из доступных оригиналов подготовь нужные страницы, не заменяй редакции. Нормативы и лицензируемый SDK — только из законно предоставленных владельцем локальных материалов. Не пытайся обходить 403, лицензии или ограничения среды. При отсутствии отдельных файлов продолжи другие задания.

Ты обязан самостоятельно выбрать необходимые инструменты и проверить их работоспособность. Если подходящего средства нет, предприми разумную попытку установки или альтернативного решения в изолированной рабочей папке. Выбор PDF/OCR, CAD, офисных, компилятора, браузера, SQL и других средств — твоя ответственность; конкретные программы не предписаны. Разрешено получать зависимости из доверенных официальных реестров ПО только на этапе настройки; запрещено искать решения, вводить секреты, устанавливать системные пакеты, sudo, изменять HOST, CT128/130/132, рабочие сервисы, настройки GPU и модели. Если среда не разрешает установку, зафиксируй причину, попробуй имеющиеся средства. Не трать весь тест на одну зависимость. Неиспользуемые инструменты не устанавливай. Отдельно измерь delivery_seconds, setup_seconds, install_seconds (часть setup), список попыток tool_setup (tool,purpose,status,wall_seconds,version,evidence). Таймер должен быть внешним; при отсутствии реального замера — null. Не считай таймер запуска скрипта временем генерации.

ЭТАП B — РЕШЕНИЕ: после подготовки сеть запрещена, кроме №48, где разрешён поиск официальных источников. Для каждой задачи используйте только её входы; зависимость CAD11 от CAD10 и CAD82 от CAD81 разрешена. При работе с внешними документами использовать карты исходных страниц. Задания 13/44/45 проверяют нативный контекст: поиск по файлу не подтверждает окно, пометь partial/context_unverified; при доказанной неподдерживаемой длине unsupported. №12/97: фактические вызовы CLI/RPC/native разрешены, протокол отдельно. Для файловых задач фактически создавай артефакты, открывай/проверяй их; отсутствие обязательного артефакта — partial, а не completed. №49 — допускаемый в исходной задаче fallback с выполненными mock-тестами, отдельно от реального SDK. Если при решении обнаружилась зависимость, останови таймер решения (если внешний оркестратор умеет), установи её в отдельной setup-фазе, затем возобнови; иначе не вычитай время задним числом, отметь overlap. Общий бюджет решения 7200 с, без искусственных пауз. Не прекращай весь тест из-за одного препятствия. В обычном чате работай блоками, отдавай реальный checkpoint при ограничении вывода; не обещай фоновую работу.

ЭТАП C — ОТЧЁТ. Заполни ceb-3-run.json по run-template.json: все 100 ID в порядке, для core50 новые 50 not_run/not_selected. Для каждого: status completed/partial/blocked/failed/timeout/unsupported/not_run, reason_code, answer, evidence, artifacts (реальные относительные имена), started_at/ended_at/wall_seconds только внешний замер либо null. completed означает результат представлен, а не правильность. Полные ответы и артефакты — владельцу; не публикуй секреты, ключи и ответы в GitHub. Не назначай баллы. Статус exploratory или incomplete; независимый зачёт только после подтверждения входов, среды, изоляции и оценки. Время доставки, настройки, установки, решения, проверки и полное время различаются. Отсутствующие метрики null. Доставь JSON и архив артефактов.
