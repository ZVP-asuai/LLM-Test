Безопасность и публикация результатов

В 49 заданиях внешний поиск запрещён; единственное исключение — live_search с официальными источниками. Локальные инструменты по allowlist. Оценщик фиксирует журналы самостоятельно; испытуемая модель не должна иметь доступа к эталонам, GitHub с ответами, предыдущим прогонам и секретам. Скрытый вариант обязателен для проверки обобщения.

В дальнейшем независимый оценщик публикует обезличенный агрегат в runs.json через отдельную учётную запись. Подробные ответы, сравнение, артефакты и ключи — закрытый репозиторий владельца. Автоматическое выполнение и публикация пока не подключены. CT128 не изменялся.
