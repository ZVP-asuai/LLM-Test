# CEB: запуск и импорт 2.2

**Обычный чат:** [полный промпт](chat-start.txt), [компактный шаблон](chat-template.json). Не требует API, изоляции, обязательных хешей или замеров. Выполняет доступные задания, остальные помечает по причине. Результат `ceb-chat-result.json` автоматически нормализуется до 50 строк; `exploratory` не является зачётным результатом. Частичные ответы содержат фактическую работу; пустой preflight не оценивается. Если нужен ещё ответ, продолжить в том же чате и собрать итоговый JSON. Не импортировать промежуточные checkpoint поверх уже сохранённого ID.

**Оркестратор:** [промпт](orchestrator-prompt.txt), [полный шаблон](submission-template.json). Схема 2.2, обязательная изоляция и внешний таймер только для submitted; реальная оценка отдельно. Старый 2.1 incomplete без variant_id принят как историческая диагностика. Нет вымышленных метрик. Схема формы не доказывает подлинность телеметрии или хеша. Для полного прогона всё ещё необходимы SDK, среды инструментов, фиксированные входы, токенизаторы и закрытие технической приёмки.

**Входы:** [ZIP](../inputs/input-pack.zip), [каталог](../inputs/catalog.json), [инвентарь](../inputs/inventory.json). Учебные PDF и preview подготовлены из исходного набора; контекстные preview не сертифицируют длину. Внешние PDF скачиваются только по разрешённым адресам и сверяются по редакции. Нормативы/SDK предоставляет владелец. Синтетический каталог tool service предоставлен с эмулятором. Не читать генератор при решении. `inputs/fixtures/runs.json` — учебный файл, `v2/runs.json` — реестр, запрещён испытуемому агенту.

**Коды причин:** not_started, missing_input, missing_tool, unsupported_context, dependency_failed, time_limit, runtime_error, invalid_output, policy_block, measurement_unavailable, not_selected, other, missing_artifact, context_unverified, source_unverified, output_limit, missing_sdk, missing_normative. completed, partial, failed, timeout, blocked, not_run, unsupported. В chat формате только ID, status, answer, evidence, reason_code, notes, artifacts и необязательные timestamps/wall_seconds. Для completed/partial обязателен содержательный ответ. Оценки запрещены.

**Сохранение:** импорт в браузере нормализует отчёт; публикуется только сводка, не ответы. Для сохранения ответов в браузере — отдельный флажок; для публикации — [GitHub Actions](https://github.com/ZVP-asuai/LLM-Test/actions/workflows/ceb-import.yml), `gh workflow run ceb-import.yml --repo ZVP-asuai/LLM-Test --ref main --json < ceb-dispatch.json`. Сводка записывается после авторизации владельца. Никаких токенов на странице. Дубликат ID не перезаписывается. Внешнее оценивание и доверенная телеметрия — отдельные этапы.

Уточнения определения полей и частичного исполнения: `inputs/catalog.json`, поле `clarifications`. В интерфейсе допускается не только файл, но и вставка полного JSON из чата. Если сохранение ответов не отмечено, они не записываются в localStorage. Ключи и содержимое ответов не входят в публичную сводку.
