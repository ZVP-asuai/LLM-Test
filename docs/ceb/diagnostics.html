Проверка владельцем

1. Открыть каталог, скопировать «Обычный чат». 2. Вставить во временный чат. 3. Проверить реальные решения, включая №1. 4. При ограничении длины продолжить следующим блоком. 5. Импортировать итоговый файл на странице сравнения. Нулевой preflight не является успешной приёмкой.

Полная квалификация ещё зависит от оригинальных PDF, реального SDK/нормативов, токенизаторов, выполнения CAD и независимого оценщика. Само наличие файла JSON не доказывает качество решения.
