# LLM-Test — CT128 GPU LAB

Центральный журнал исследований локальных LLM, GPU и inference-движков. Репозиторий хранит воспроизводимые конфигурации, сырые измерения, результаты тестов, технические решения и HTML-отчёты.

Подробная структура, правила ведения экспериментов и текущая панель лаборатории будут добавлены отдельными файлами.
