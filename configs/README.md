# Конфигурации

Здесь хранятся безопасные текстовые профили запуска и параметры движков.

Правила:
- сохранять исходный профиль отдельно от экспериментального;
- включать версию движка и назначение в имя файла;
- не сохранять секреты, токены, приватные ключи и бинарные веса;
- указывать, какие параметры подтверждены фактическим запуском;
- перед изменением действующего профиля сохранять копию и способ отката.

Пока зафиксирована только информация о первом профиле Strata в engines/strata/README.md. Полный исходный JSON-конфиг в репозиторий не переносился.
