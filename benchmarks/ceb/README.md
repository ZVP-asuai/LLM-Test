# CEB Engineering Benchmark 1.2 Review

- [Каталог промптов и ожидаемых результатов](../../docs/ceb/index.html)
- [Пул заданий JSON](../../docs/ceb/tasks.json)

12 обязательных заданий, 100 баллов, 117 минут + 3 минуты резерва. 6 дополнительных направлений. Статус: подготовка, без запусков локальных моделей. Публичный каталог содержит только задания и ссылки на оригиналы, закрытые эталоны хранятся отдельно у владельца. Синтетические PDF и длинный контекст передаются агенту в отдельном комплекте. Оценщик не передаёт ключи, контрольные ответы или результаты предыдущих моделей в исполняемый контур. Реальный запуск требует проверки источников и токенизатора; дополнительный EPLAN API требует SDK, нормативы — фиксированного лицензированного корпуса.
